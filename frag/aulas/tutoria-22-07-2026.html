Importando arquivo CSV no Google Colab (dúvida da Sheila, que não achava os arquivos):

  • No Colab, o arquivo é enviado pela "pastinha" (ícone de arquivos) ou arrastando para o ambiente. Há uma pasta sample_data com dados de exemplo.
  • CSV = Comma Separated Values: primeira linha tem os nomes das colunas; cada linha seguinte é uma instância de dado.
  • Para ler CSV, normalmente se usa a biblioteca Pandas (import pandas as pd).
  • Os arquivos de dados dos exercícios estão no final da quinzena 1, num .zip no Drive ("arquivos de dados para os exercícios") — a Sheila encontrou e baixou.
  • Caminho do arquivo: no Colab é preciso subir o arquivo para o ambiente; no VS Code o arquivo já está no computador, basta apontar para a pasta certa (opção "copiar caminho").

Configurando o VS Code do zero (passo a passo mostrado pelo Gustavo):

  • Criar um arquivo .ipynb (formato de notebook) ou .py (Python).
  • O VS Code pede para escolher um kernel (interpretador Python com as bibliotecas). Criar um novo ambiente (ex.: Python 3.9).
  • import pandas dá erro até instalar a biblioteca com o gerenciador Pip: pip install pandas (que traz dependências como NumPy e tzdata).
  • Depois de instalado no kernel, os notebooks seguintes reutilizam as bibliotecas (ver com pip list).
  • Ambiente virtual (venv): isola bibliotecas por projeto, evitando conflitos de versões entre projetos. Para ativar no Windows: venv\Scripts\activate (sem source, que é do Linux).
  • Caso do Carlos (computador da empresa): o VS Code não achava o kernel/Python; a solução passava por criar/ativar o venv e instalar o Pip — mas a política de segurança da empresa bloqueava a instalação, então ele precisaria pedir liberação à TI.

Pontos-chave / Decisões ou orientações

  • Importar CSV no Colab: enviar o arquivo pelo painel de arquivos e ler com Pandas; arquivos dos exercícios vêm num .zip no Drive.
  • VS Code: precisa de kernel Python + bibliotecas instaladas via Pip; ambiente virtual (venv) isola bibliotecas por projeto.
  • Colab é mais simples para começar (tudo pronto); VS Code é melhor para dados grandes/sensíveis (privacidade).
  • Presença = fazer a atividade quinzenal; nota = atividades quinzenais + avaliação final.

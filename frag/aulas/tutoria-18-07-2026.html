Exercício 18 resolvido ao vivo (dúvida do Marcos):

  • Contexto: dois arrays NumPy com notas de 1 a 10 para 4 serviços de duas empresas concorrentes, A (10 notas) e B (5 notas), organizadas em linhas; há uma lista de pesos. O exercício pede: (1) média das notas de cada serviço (usando redução); (2) para cada serviço, a menor nota de A considerando apenas as notas maiores que a média de B daquele serviço; (3) armazenar essas notas mínimas num novo array de 4 elementos; (4) soma das notas mínimas ponderadas pelos pesos (multiplicação vetorial).
  • Dificuldade do Marcos: comparar o array de A com a média de B dava erro de tamanho de arrays (broadcast não acontece automaticamente quando os tamanhos não batem).
  • Estratégia mostrada:

1. Calcular a média de B por linha (ex.: com list comprehension [np.mean(row) for row in B]).

2. Usar enumerate para iterar por linha e coluna de A, comparando cada valor com a média de B daquela linha (índice).

3. Para valores que não passam no filtro, usar um "valor inválido" — como as notas vão de 1 a 10, usar 11 (nota inválida) em vez de 0, para não atrapalhar o cálculo do mínimo.

4. Aplicar np.min(..., axis=1) para obter a menor nota de cada linha.

5. Multiplicar vetorialmente pelos pesos e somar.

  • Lição central: quebrar o problema em etapas menores — primeiro resolver cada parte, depois otimizar (ex.: juntar tudo num list comprehension). Não é preciso começar pela solução mais elegante.

np.min vs min de lista (dúvida de outro aluno):

  • Para esse exercício, a diferença é irrelevante (poucas comparações). Em geral, np.min tende a ser mais rápido porque o NumPy é implementado em C. A forma de decidir é consultar a documentação e comparar a complexidade (Big O) de cada função.

Gustavo fez uma "mapeada" inicial dos conceitos fundamentais:

- **O que é Python**: uma linguagem de programação. O computador só entende zeros e uns (linguagem binária); o código em Python é um texto que um interpretador traduz para a máquina. Python é declarativo, tem tipagem dinâmica (não é obrigatório declarar o tipo da variável) e tem curva de aprendizado simples. Para ciência de dados, é muito usado porque permite produzir rápido e tem muitas bibliotecas prontas.
- **Arquivo `.py` vs notebook**: o `.py` é um arquivo de texto Python que precisa de um interpretador instalado. O notebook (ex.: Google Colab) é dividido em células que aceitam código ou texto, o que facilita anotações e aprendizado. Todo o material do curso está em notebooks.

Em seguida, foram tiradas dúvidas práticas:

- **Colab vs VS Code**: para o curso, a recomendação é usar o Colab (acesso pelo navegador, mais simples). Deixar o VS Code para depois.
- **Aspas simples vs duplas (strings)**: não existe hierarquia entre elas — ambas produzem string. O que importa é manter um padrão no código e saber que é possível usar aspas simples dentro de aspas duplas (ex.: citação dentro de uma frase). A professora Mirela falou em padronização; Gustavo reforçou que o importante é entender o tipo de dado.
- **Tipos de dados**: `int` (inteiro), `float` (número com vírgula), `string` (sequência de caracteres). Mostrou no Colab o uso de `print`, `type` e casting (converter um tipo em outro). Explicou que tipos diferentes usam espaços de memória diferentes (nível de bits) e que isso pode fazer diferença em casos específicos.
- **SQL dentro de Python**: Felipe perguntou sobre o uso de três aspas duplas para passar queries SQL dentro do código Python. Gustavo explicou que isso é um escape usado pelas bibliotecas para identificar que aquele trecho é SQL (outra linguagem).
- **Listas e matrizes**: Python é *zero-based* (índices começam em 0). Para acessar um elemento de lista usa-se `lista[índice]`; para matrizes (lista de listas), usam-se dois colchetes — quanto mais profundo o nível, mais colchetes. Mostrou exemplos com lista de compras, matrizes, índice `-1` (último elemento), fatiamento (`lista[:3]`) e o erro `List index out of range` quando o índice não existe.
- **Listas dentro de listas e dicionários**: para referenciar listas por nome (ex.: "leguminosas", "frutas"), a estrutura correta é o **dicionário** (chave → valor), que será visto nas próximas aulas.

## Pontos-chave / Decisões ou orientações

- Python é uma linguagem de programação interpretada, declarativa e de tipagem dinâmica; ideal para ciência de dados pela rapidez de produção e pelas bibliotecas.
- Notebook (Colab) ≠ arquivo `.py`: notebook é dividido em células de código e texto; é o formato usado no curso.
- Para este momento do curso, usar o **Colab**; o VS Code pode ficar para depois.
- Aspas simples e duplas são equivalentes em Python; o importante é manter um padrão e conhecer os tipos de dados.
- Tipos de dados (`int`, `float`, `string`) ocupam espaços de memória diferentes; casting converte um tipo em outro.
- Python é *zero-based*: listas começam no índice 0; `-1` acessa o último elemento; fatiamento usa `[:n]`.
- Matrizes são listas de listas; o número de colchetes indica a profundidade do acesso.
- Dicionários (chave → valor) permitem nomear estruturas; serão vistos nas próximas aulas.
- Não existe pergunta boba: dúvidas devem ir para o fórum do curso 1.

15. **Exemplo 4 — laço `while` (poupança)**: guardar R$ 300/mês até meta de R$ 1000: `while poupanca < meta: poupanca += 300; mes += 1` → 4 meses. A condição é reconferida a cada iteração; quando falsa, pula o bloco.

## Pontos-chave / Decisões

- Variável: caixa nomeada; `=` é atribuição (direita → esquerda).
- Tipos: str, float, int, bool; Python define o tipo pelo valor; `type()` consulta.
- `print` exibe; f-string mistura texto + variáveis (`{var}`), `:.2f` formata float.
- `input` retorna string — converter (`float`, `int`) quando necessário.
- Teste de mesa: acompanhar o estado das variáveis linha a linha (HTML criado com IA).
- Troca de valores precisa de variável temporária.
- `if/else` escolhe caminho; `for` itera sobre valores conhecidos; `while` repete enquanto a condição for verdadeira (reconferida a cada laço).
- Acumulador: `total = 0` antes do laço; `total += v`.
- Blocos definidos por indentação (não por chaves).
- Fatiamento: `[inicio:fim]` com fim aberto (fim − 1); `append` adiciona no fim; atribuição por índice substitui.
- "Pense em Python" como referência aberta.

> Tutoria de revisão conduzida pelo tutor William Cardoso. Faz um "resumão" das dúvidas de sintaxe mais comuns nas tutorias anteriores (input/tipos, range, end/\n, for vs while, indentação, função e retorno, f-string, set, count, if/elif/else) e resolve os últimos exercícios de fixação do curso zero: série de pares, elementos que aparecem uma única vez e números primos num intervalo.

## O que foi coberto (cronológico)

1. **`input` e por que usar `int`/`float`**: `input` sempre retorna **string** — não dá para fazer operações matemáticas. Converter com `int(...)`/`float(...)` conforme a necessidade. Conferir tipo com `type(variavel)`.
2. **`TypeError`**: operações com tipos diferentes (ex.: `5 + "5"`) geram erro de tipo; errar faz parte de programar.
3. **`range`**: sequência numérica; **o último número é exclusivo** (zero a N−1). Convenção Python (indexação do zero) — facilita operações com listas/vetores. Dica: para incluir o final, use N+1.
4. **`end` (parâmetro do print)**: o print tem um parâmetro invisível `\n` (caractere da **tabela ASCII**) que pula linha. Com `end=''`/`end=', '` dá para controlar o final da impressão. `\r` também existe (retorno de carro). Caracteres especiais podem causar bugs em arquivos/planilhas.
5. **`for` vs `while`**: `for` = quantas vezes se repete (sabe-se o nº de iterações, sobre valores conhecidos). `while` = depende de uma **condição** (lógica); exemplo de `while True` em interfaces/jogos (loop de frames atrás de programas).
6. **Indentação**: bloco/contexto em Python definido pela indentação (tab/4 espaços) — não por chaves. Depois de `:` precisa de um bloco; se errar, `IndentationError`. Blocos aninhados (funções dentro de condições) aumentam o nível. IDE colorida (VS Code) ajuda a visualizar.
7. **Funções**: bloco de código **reutilizável**, definida com `def`. Exemplo real: função `enviar_email()` chamada em vários pontos de um e-commerce (evita repetir 100 linhas). `return` devolve um valor para usar na sequência (ex.: log com ID do e-mail). Sem `return`, retorna `None`.
8. **f-string**: "template string" — edita uma string de forma **dinâmica** (`f"{usuario} enviou..."`); sem ela, fica estático/concatenado (`+`), ilegível com muitos trechos. Antes existia `format`. Exemplo prático LLM: template fixo + entrada que varia (imagem).
9. **`set`**: conjunto — remove duplicados e permite operações de conjuntos (intersecção etc.). `Control+Espaço` no Colab mostra as opções (pop, remove, clear, copy...). Diferente de lista (sem `count`, pois não há duplicados).
10. **`count`**: conta ocorrências (`lista.count(1)`); alternativa manual com `while` + contador.
11. **`if/if` vs `if/elif`**: dois `if` seguidos executam as duas sequências quando ambas as condições valem; `if/elif` pára no primeiro verdadeiro. `elif` = "senão se".
12. **Exercício 1 — N primeiros pares positivos**: `for i in range(n)`; `termo = 2 * i` e print com `end=', '` para separar (e sem vírgula no último). Testado com n = 2, 5, 6 (saídas: 0.2; 0,2,4,6,8; etc.).
13. **Exercício 2 — elementos que aparecem exatamente uma vez**: função recebe lista; percorre `set(lista)` (elementos únicos); se `lista.count(item) == 1`, adiciona a `result`; `return result`. Erro `NameError` mostrado: chamar função/variável inexistente ("lista not defined").
14. **Exercício 3 — números primos num intervalo**: função `primos(inicio, fim)`; `for numero in range(inicio, fim+1)` (fim **inclusive**, lembrando exclusão do range); `if numero < 2: continue`; assume primo e testa divisores de 2 até número (`if numero % divisor == 0:` → não é primo, `break`); se primo, `resultado.append(numero)`. Saída para intervalo dito: 2, 3, 5, 7. Números primos exigem loop (só comparando divisores); computacionalmente caro.
15. **Encerramento**: material com os erros comentados para fixar tipos de erro; dúvidas no chat/fórum.

## Pontos-chave / Decisões

- `input` retorna string → converter com `int`/`float`; `type()` confere.
- `TypeError`: operação entre tipos incompatíveis.
- `range(N)` vai de 0 a N−1 (fim exclusivo).
- `end='...'` controla o final do print; `\n` (ASCII) pula linha por padrão.
- `for` (nº conhecido de iterações) vs `while` (depende de condição; `while True` em interfaces).
- Indentação define blocos/contexto; `:` requer bloco.
- Função = código reutilizável (`def`); `return` devolve valor (sem ele, `None`).
- f-string = string dinâmica; evita concatenação ilegível.
- `set` remove duplicados e faz operações de conjuntos; `count` conta ocorrências.
- `if/if` → executa todas as condições verdadeiras; `if/elif` → pára na primeira verdadeira.
- Números primos exigem teste de divisibilidade (loop; computacionalmente caro).

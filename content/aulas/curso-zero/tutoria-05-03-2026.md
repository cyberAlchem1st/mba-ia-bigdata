# Tutoria 05/03/2026 — Análise Automatizada de Notas Fiscais em PDF

> **Resumo didático**
> Tutoria com os professores Lucas e Mirella. Estudo de caso real (inspirado em um problema do fórum, trazido pela aluna Júlia): automatizar a análise de 1000 notas fiscais em PDF — carregar PDFs de um diretório, extrair texto com PyPDF2 e responder perguntas com manipulação de strings e regex (protocolo, palavras-chave, valor total via regex, pagamento em Pix).

## O que foi coberto (cronológico)

1. **Cenário real (Júlia)**: e-mail com anexos (comprovantes, notas fiscais) → múltiplos módulos: monitorar e-mail/procurar PDFs, automação central, decidir se é nota fiscal, extrair dados, banco de dados, interface. O estudo de caso é a simplificação do "módulo de PDF".
2. **Enunciado**: estagiário recebeu 1000 notas fiscais em PDF (ficção). Etapas: carregar PDFs, extrair texto, identificar arquivo com protocolo LGX, contar notas com "toner", "notebook", ambos (+ porcentagem), somar o valor total das notas e o total em Pix (+ porcentagem).
3. **Montar o Drive**: `from google.colab import drive; drive.mount('/content/drive')` para acessar as notas fiscais salvas no Google Drive.
4. **Biblioteca de PDF**: PyPDF2 (leitura/escrita de PDF). Discussão: bibliotecas Python mudam rápido (PyPDF2 virou PyPDF); o que importa é saber ler documentação e usar classes/objetos/métodos.
5. **Listar arquivos**: `os.listdir(pasta)` retorna lista de arquivos; filtrar só `.pdf` com list comprehension + `.lower()` e `.endswith('.pdf')`; `.len` = 1000 (a pasta tem 1000 PDFs + 1 CSV = 1001 itens).
6. **Caminho completo**: usar `os.path.join(pasta, arquivo)` em vez de concatenar com `+` (portabilidade entre SOs — barras diferentes no Windows).
7. **Extrair texto**: `open(caminho, 'rb')` (leitura binária) → `PyPDF2.PdfReader(arquivo)` → para cada página (`for pagina in pdf.pages`), `texto += pagina.extract_text()` (usar `+=`, senão fica só a última página). `extract_text` é método (autocomplete mostra cubo); `.pages` é atributo.
8. **O texto vira string**: a estrutura do PDF se perde (formatação); mas agora a manipulação é só de **strings** — conteúdo vira o "corpo" que se analisa.
9. **Dicionário de notas**: `notas = dict()` com chave = nome do arquivo, valor = conteúdo em string. Iterar com `for arquivo, conteudo in notas.items()`.
10. **Progresso com `enumerate`**: `for count, arquivo in enumerate(...)` dá contador automático para exibir progresso ("lendo PDF nº X").
11. **Buscar protocolo**: `if protocolo in conteudo:` → f-string com o nome do arquivo. Pode virar função para reutilizar.
12. **Contar palavras**: `if 'toner' in conteudo.lower():` (`.lower()` para não perder maiúsculas), `conta_toner += 1`; idem notebook; ambos: `if 'toner' in ... and 'notebook' in ...`. Sugestão: converter tudo para lower uma vez antes (mais eficiente).
13. **Porcentagem**: parte/todo × 100 — `conta_toner / len(notas) * 100`, formatado com `:.2f`. Resultados: toner 37,8%, etc.
14. **Regex para o valor total**: padrão `r'TOTAL.*?\*\*?` capturando o numeral entre parênteses (grupo 1): `r'R\$ ([\d.,]+)'` — `re.search(padrao, conteudo)` → `m.group(1)`. Explicação: `.` qualquer caractere, `*` zero ou mais, `?` não guloso, colchetes = conjunto de dígitos/ponto/vírgula.
15. **Formatar valor BR→Python**: string vem como "1.547,89" (formato pt-BR). Remover pontos (`.replace('.', '')`) e trocar vírgula por ponto (`.replace(',', '.')`), depois `float()`.
16. **Somar total**: `valor_total += float(...)`, arredondado com `:.2f`; conferir com o CSV de referência (R$ 6.233.000).
17. **Pix**: `if ' pix ' in conteudo.lower():` (com espaços para ser palavra separada — simplificação) → somar `valor_total_pix`; porcentagem do total ≈ 21,14%.
18. **Discussões finais**: LLM para casos mais complexos (formatação, comentários, casos de borda) — aula extra gravada sobre LLMs (ex.: Groq com API/playground, código gerado). Dados confidenciais → modelos locais (Ollama, LM Studio). OCR (PyTesseract/PaddleOCR) para PDFs com imagem. Limitação do exercício (busca exata) reconhecida. Lentidão ao ler muitos arquivos pequenos do Drive — testar local.
19. **Encerramento**: material do Lucas + exemplo de leitura de e-mail (Mirella) serão disponibilizados.

## Pontos-chave / Decisões

- Quebrar problema em módulos e reutilizar (ideia central do cenário real).
- `os.listdir` + filtro `.endswith('.pdf')`; `os.path.join` para caminhos portáveis.
- PyPDF2: `open('rb')` → `PdfReader` → `for pagina: texto += pagina.extract_text()`.
- PDF vira string → análise = manipulação de strings (.lower(), .replace(), in).
- Dicionário: chave = nome do arquivo, valor = conteúdo; `for k, v in dict.items()`.
- `enumerate` para progresso em loops.
- `re.search(padrao, texto)` + `.group(1)` para capturar padrões (valor total).
- Regex captura: parênteses = grupo, `[0-9.,]` = conjunto, `*` = zero ou mais.
- Converter formato pt-BR (1.234,56) para Python (1234.56) com replace.
- Porcentagem = parte/todo × 100, `:.2f`.
- LLM compensa onde busca exata falha; OCR para PDF digitalizado.

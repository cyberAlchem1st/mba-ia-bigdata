7. **Exercício 2 — carteira de estudante/trabalho**: idade → 3 saídas:
   - `if idade >= 18` (transcrição usa idade 16/18 conforme enunciado original: 14 estudante, 16 trabalho) — "pode tirar carteira de estudante e trabalhar formalmente".
   - `elif idade >= 14` — "pode tirar carteira de estudante, mas não pode trabalhar".
   - `else` — "não pode tirar carteira de estudante ou trabalhar".
   - Conceitos: `input` + `int` (conversão), `if`/`elif`/`else` (senão-se/senão), indentação (blocos com `:`), testar cada bloco à medida que escreve.
8. **Exercício 3 — cadastro de voluntário (18 a 90 anos)**: ler dia/mês/ano de nascimento + data atual; calcular idade (`ano_atual - ano_nascimento`), ajustar se ainda não fez aniversário (`if mês_atual < mês_nasc or (mês_atual == mês_nasc and dia_atual < dia_nasc): idade -= 1`); verificar `if 18 <= idade <= 90:` (comparação encadeada) e `else`.
9. **Dúvidas técnicas (Jonas, do mainframe/COBOL)**:
   - `idade -= 1` = `idade = idade - 1` (abreviação).
   - Comparação encadeada `18 <= idade <= 90` lê-se "idade maior/igual a 18 e menor/igual a 90" — são duas comparações simultâneas.
   - **Performance**: código de 1 linha vs. vários passos → sem ganho significativo; Python prioriza legibilidade; estrutura de dados (listas, sets, list comprehension) e dataset massivo mudam isso em casos avançados.
   - `~` sobre `else if` → no Python se usa `elif`; em COBOL há diferenças de sintaxe (necessidade de parênteses, etc.).
   - Trocar comparadores/tipos (int, string, boolean) importa com volume massivo de dados.
10. **Erro `TypeError`**: operações entre tipos incompatíveis (ex.: `int` − `string`); explicado o fluxo `input` (string) → `int` (conversão); erro de conversão ao comparar mês (string vs int).
11. **Como submeter exercícios**: desenvolva a solução do seu jeito, só coloca a resposta; não há validação automática do "jeito" de programar.

## Pontos-chave / Decisões

- Tutorias opcionais; curso 15 (palestras) tem nota mínima 7.
- `input` retorna texto → `int()`/`float()` para operações numéricas.
- `if`/`elif`/`else` + indentação (blocos de 4 espaços com `:`); erros de indentação são comuns no início.
- Comparação encadeada `18 <= idade <= 90` (duas comparações).
- `idade -= 1` é decremento (abreviação de `idade = idade - 1`).
- Python é interpretado e prioriza legibilidade; otimização relevante só em dados massivos.
- `TypeError` = operação entre tipos incompatíveis (ex.: int com string).
- Dica: desativar o assistente de IA do Colab no início para fixar a escrita de código.
- Testar cada bloco conforme escreve para pegar erros de indentação cedo.
- Material de tutorias fica no Moodle: resumo + slides/notebooks + vídeo.
- Conteúdo extra (não listado nas aulas) é estudável; ajustes vão ser postados no fórum.

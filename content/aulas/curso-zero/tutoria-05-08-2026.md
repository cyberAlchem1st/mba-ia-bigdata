> **Resumo didático**

## O que foi coberto (cronológico)

1. **Dúvida da atividade quinzenal (Safira)**: exercício 5 parecia inverter a lista, mas é um **bubble sort**. Explicação: para cada item, compara `lista[j]` com `lista[j+1]` e troca quando necessário (`temp`); sempre compara com o item à frente → ordenação crescente, não inversão. É um dos algoritmos de ordenação mais lentos (força bruta). Inversão aconteceria se trocasse com o último item.
2. **Exercício 1 — classificação de números**: ler 5 números inteiros (`for i in range(5)`), com `int(input(...))` e f-strings. Verificar intervalo `if numero <= 100` (e ≥ 1 conforme enunciado) → "número válido"/"fora do intervalo"; contar pares (`numero % 2 == 0`) e ímpares com contadores (`pares += 1`/`impares += 1`); exibir total no final.
3. **Exercício 2 — contador de vogais (função)**: `def contar_vogais(palavra)` percorre `for letra in palavra.lower()` (ignorar maiúsculas/minúsculas) e conta quando `letra in "aeiou"`. Retorna o `contador`. Loop `while True` pedindo palavras até o usuário digitar "sair" (`if palavra.lower() == "sair": break`). `print(..., end="\n")` para não amontoar.
   - **Erro demonstrado**: esquecer `return contador` → função retorna `None` (o print mostrou "None").
   - Conceito: `while` quando não se sabe quantas repetições (nº de palavras é imprevisível); `for` quando se sabe (letras da palavra).
4. **Exercício 3 — agenda de contatos**: lista `contatos`; `while len(contatos) < 3` pede nome e telefone; validação `if telefone.isdigit() and len(telefone) == 9:` → `contatos.append({"nome": nome, "telefone": telefone})` + mensagem com `end="\n"`; senão "telefone inválido, tente novamente" (não conta como cadastro). Ao final, percorre e imprime nome e telefone.
   - **`isdigit`**: verifica se todos os caracteres são dígitos (número com `+`, letras ou símbolos → False; zero à frente → True).
   - **Nota de modelagem**: telefone/CPF/CNPJ devem ser **string** (não int) — números podem começar com zero (DDD, CPF tipo 083) e quebra(riam) em banco que salva inteiro.
   - Estrutura: lista de dicionários (muito comum em sistemas — entidade com vários campos).
5. **Apêndice — envio de e-mail com f-strings (Resend)**: demonstra aplicação real dos conceitos (funções, f-strings, dicionários, loops).
   - Função `enviar_email(nome, email, assunto)` com f-string + docstring (três aspas preservam quebras de linha) montando o corpo "Olá, {nome}...".
   - Dicionário `{"from": ..., "to": email, "subject": assunto, "text": corpo}` passado ao `resend.Emails.send(...)` (a API exige esses campos — documentação).
   - **API Key**: necessária para autenticar (só funciona seu domínio/configuração).
   - E-mail real enviado ("Olá, William Cardoso, este é um e-mail de teste...") e confirmado na caixa de entrada.
   - Função reutilizável: chamar 10× envia 10 e-mails; percorrer uma lista de contatos com `for` envia para todos (código comentado como exercício).
   - Exemplo de mensagem HTML (e-mails de marketing) mencionada como extensão.
6. **Encerramento**: o uso prático motiva associar os conceitos; material com comentários detalhados será disponibilizado.

## Pontos-chave / Decisões

- Bubble sort: comparar cada item com o seguinte e trocar → ordena (não inverte).
- `for i in range(n)` para nº conhecido de repetições; `while True` + `break` para repetição indefinida (ex.: até digitar "sair").
- `numero % 2 == 0` → par; contadores `+= 1`.
- `.lower()` padroniza para validação/contagem de letras (case-insensitive).
- Função sem `return` retorna `None`.
- `isdigit()` e `len()` validam telefone; telefone/CPF/CNPJ como **string** (zeros à esquerda).
- Lista de dicionários para entidades com vários campos.
- f-strings/dict para montar mensagens dinâmicas; bibliotecas (ex.: Resend) + documentação para tarefas prontas (envio de e-mail); API Key para autenticar.
- Funções são reutilizadas em vários pontos do sistema.

No desenvolvimento, a gente vai projetar uma solução, codificar essa solução e rodar e testar o programa. A primeira etapa do desenvolvimento é justamente projetar a solução usando um algoritmo. Um algoritmo é uma sequência de passos que visam atingir um objetivo bem definido. Pessoas têm inteligência e habilidade racional, por isso fazem perguntas para se esclarecer. Computadores não têm senso próprio, por isso eles devem receber instruções explícitas e precisas. Um algoritmo correto deve possuir três qualidades: cada passo do algoritmo deve ser uma instrução que possa ser realizada; a ordem dos passos deve ser precisamente determinada; e o algoritmo deve ter um fim. Todo algoritmo possui início, instruções e o fim. Cada instrução termina com ponto e vírgula, e o algoritmo termina aqui com o ponto final. Vamos fazer o nosso primeiro algoritmo. Para isso, vamos usar uma tarefa que todo mundo conhece e provavelmente já fez. Vamos fazer um algoritmo pra trocar uma lâmpada no teto. Quais serão as instruções? Vamos usar para as instruções o português coloquial. Temos aqui o início do algoritmo, temos uma ação, remover a lâmpada queimada, outra ação que é: coloque a nova lâmpada, e termina o algoritmo. O problema aqui é que essas ações são muito complexas. A gente vai quebrá-las em passos menores. Por exemplo, o que é necessário pra você remover a lâmpada queimada? Tipos de dados. Os dados são computacionalmente representados através de constantes e variáveis, que possuem um tipo de dado associado a ela. Uma variável pode ser um número inteiro, um número real e por aí vai. Dizemos que uma determinada constante ou variável é de um determinado tipo, porque ela vai armazenar valores deste tipo. Tipo de dados são métodos para interpretar o conteúdo da memória do computador. Ele define o conjunto de valores que uma variável pode assumir. Por exemplo, um tipo específico de dados especifica a quantidade de bytes que deve ser reservada pra uma constante ou variável, quando essa constante ou variável vão armazenar esse tipo de dado. E também como o dado representado por esses bytes deve ser interpretado. O que significa essa cadeia de bits. Por exemplo, você pode ter um dado numérico, então aquilo ali vai representar números, você pode ter uma string, então aqueles bytes vão representar letras e números. Então o computador precisa saber o tipo pra saber como ele vai interpretar os dados das variáveis e constantes. As linguagens de programação conseguem manipular um conjunto de tipos de dados. Dentre eles, os tipos primitivos de dados básicos são classificados em numéricos, literais e lógicos. Os dados numéricos podem ser basicamente de dois tipos de dados: inteiros, que não possuem casa decimal, como 27, 4,56, 1000. Reais, que possuem partes decimais. 203.53, 8.5, 3.14, 1.2. Os dados literais são conjuntos de símbolos que podem ser formados por caracteres. São números, letras e símbolos especiais. Uma string é uma sequência de caracteres. Por exemplo, aqui tem uma string aula, a string 6, que tem um caractere só, a string 987 e essa string aqui que tem, além de letras e números, tem símbolos especiais como porcentagem, multiplicação e comercial. Nós também temos os dados lógicos, que são utilizados pra representar dois valores únicos, verdadeiro ou falso, true ou false. É o tipo de dado chamado lógico ou boolean. Ele também é conhecido como tipo boleano, em referência à álgebra de Boole. Variável. Matematicamente, uma variável é a representação simbólica dos elementos de um certo conjunto. Computacionalmente, cada variável corresponde a um endereço de memória cujo conteúdo pode variar ao longo do tempo na execução do programa, ou seja, ele é um local em memória pra você armazenar dados. Embora o endereço possa assumir vários valores, ele só pode armazenar um valor por vez e esse valor pode ser de qualquer tipo de dado. Você pode armazenar um inteiro, pode armazenar um real.
